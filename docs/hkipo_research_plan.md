# 港股次新股研究计划（历史主线）

> 项目当前主线已转为港股 IPO 打新研究，见 [`hkipo_subscription_research.md`](hkipo_subscription_research.md)。本文保留上市后次新股研究设计和已完成工作，作为对照。

## 研究问题

在港交所新上市普通股的上市后前 30 个交易日，利用截至决策时点可获得的 IPO 静态资料和二级市场行情，能否在扣除成本后改善长仓/空仓决策？主要评估跨 IPO 和跨市场制度的泛化，不把策略默认成可盈利。

## 阶段

1. **数据审计**：建立 IPO 主表与日线表；核对上市日期、发行价、交易单位、成交额、流通股、公司行动、停牌、退市以及特征发布时间。
2. **描述性基线**：按上市后第 1–30 个交易日统计超额收益、波动、换手、回撤和成交可用性；区分 2025-08-04 前后的 IPO 配售规则制度。
3. **监督学习**：先预测未来 1/5 日风险调整收益或尾部亏损概率；所有特征按可用时间对齐。比较发行价持有、上市首日买入后持有、动量和简单风险过滤等基准。
4. **策略回测**：先限制长仓/空仓，设置仓位上限，模拟下一可交易时点、整手数量、停牌/无量无法成交和逐边成本。
5. **序列决策**：只有在多个市场阶段的 IPO 级样本外结果稳定后，才比较 contextual bandit 与 DRL。状态应含现金、持仓、剩余事件天数和风险；奖励采用成本后增量组合收益，并控制换手和回撤。

## 评估约束

- 使用 rolling-origin / expanding-window 年度切分；一只 IPO 的完整事件轨迹只出现于一个分区。
- 以 IPO 为单位做置信区间/重采样，避免把同一只新股的多根日线误当成独立样本。
- 至少报告净收益、波动、最大回撤、尾部损失、换手、费用贡献和基准差异；同时报告每年和制度分组表现。
- 设定简单策略和随机/持有基准。阈值只在训练/验证窗口选取，不能看完整历史后再选。
- 任何绿鞋或稳定价格操作特征必须以招股文件、稳定价格期公告及实际操作披露为准；不得编码成固定价格底。

## 当前状态

项目已切换主线，完成 HKEX 年度新上市报告导入器、Yahoo/yfinance 日线抓取器、事件面板、持有期基线和按上市年份切分的 Ridge 预测基线。当前数据覆盖 2021–2026（2026 年内样本），533 个候选事件中 519 个取得日线。数据源、质量检查和模型结果见 [`hkipo_initial_results.md`](hkipo_initial_results.md)。

当前尚缺每手股数、经核验的实际成交额、完整退市/停牌覆盖、事件类型筛选、指数/市场状态及经券商确认的费用。现有持有期统计是价格行为筛选，不是可执行策略或 DRL 结果。下一步先补齐这些字段并审计覆盖率，再做时间顺序的预测基线和可执行回测。
