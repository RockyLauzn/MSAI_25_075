# 数据契约

## SPY 日线

CSV: `data/raw/spy_daily.csv`

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `date` | 日期 | 每个交易日一行；可解析为日期 |
| `adj_close` | 数值 | 有限且大于 0；统一使用调整收盘价 |

## 历史期权报价快照

CSV 或 Parquet：一行代表某个合约在某个时间点的 NBBO/供应商报价；字段必须统一到以下名称。通用回测可用盘中开盘/收盘窗口；公开数据适配器提供 16:00 ET 日终快照，供 EOD 模式次日收盘入场和指定日收盘退出：

| 字段 | 必需 | 含义 |
| --- | --- | --- |
| `quote_time` | 是 | 报价时间，带时区或明确为 UTC |
| `contract_symbol` | 是 | 供应商/交易所期权合约代码，原样保留 |
| `underlying` | 是 | 标的代码，当前研究范围为 `SPY` |
| `expiration` | 是 | 到期日 |
| `right` | 是 | `C` 看涨或 `P` 看跌 |
| `strike` | 是 | 行权价 |
| `bid`, `ask` | 是 | 买卖报价，美元/股 |
| `bid_size`, `ask_size` | 是 | 对应报价数量 |
| `underlying_price` | 是 | 报价时标的价格 |
| `contract_multiplier` | 是 | 每张合约对应股数；标准 SPY 合约通常为 100，调整合约须按真实交割单位处理 |
| `deliverable_shares`, `deliverable_cash` | 是 | 每张合约的实际交割股数与现金；策略原型仅接受 100 股、0 美元的标准合约 |
| `volume`, `open_interest` | 否 | 当日成交量、未平仓量；需记录供应商定义和可用时点 |
| `implied_volatility` | 否 | 隐含波动率；需记录计算口径和单位（建议小数，如 0.25 表示 25%） |

可选风险字段如 delta、gamma、theta、vega 可追加。数据适配器应保留原始合同代码、来源和原始时间戳，且不得用未来才公布的收盘未平仓量回填盘中决策特征。

`optionlab.option_chain.load_quote_snapshots` 当前负责基本字段、时区、期权方向、正行权价、非负报价/数量和交叉报价校验。它不校正公司行动、不推导期权代码，也不证明历史数据完整或具有交易所授权。公开样本没有提供交割单位，适配器只接受标准 OCC SPY 根代码并假定 100 股乘数；使用其他供应商时须用实际合约主数据替换此假设。
