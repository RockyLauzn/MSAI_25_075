# 港股 IPO 打新首轮结果

运行入口：

```powershell
.\.venv\Scripts\python.exe -m hkipo.subscription_study --panel data\processed\hkipo_event_panel_2021_2026.csv --output-dir reports\hkipo_subscription_2021_2026
```

## 数据范围

- 519 只 IPO 有可用且首日 OHLC 通过一致性检查的行情。
- 日期范围：2021-01-06 至 2026-10-15；2026 为年内不完整样本。
- 行情源为 Yahoo Finance/yfinance，属于探索性数据，尚未逐笔与 HKEX 核验。
- 标签是最终发行价至首日收盘的毛回报；未扣申购/融资/交易费用，未考虑中签率和获配手数。

首日平均回报显著高于中位数，且个别年度均值受极端涨幅影响。单看“收涨比例”也忽略严重的破发损失，因此不能据此推断打新有正期望收益。

## 时间顺序基线

比较两种很弱的预测：预测零回报，以及仅用此前 IPO 的扩展平均回报。整个上市事件按时间顺序逐只更新，绝不使用当前 IPO 之后的标签。

- 2024 验证段：零回报 MAE 25.4%，扩展均值 MAE 39.8%。
- 2025 测试段：零回报 MAE 44.6%，扩展均值 MAE 46.7%。
- 因此扩展均值未优于零回报基线；目前没有证据证明简单历史均值带来首日回报预测增量。
- 2025 首日收涨率为 67.0%，但用正收益作为“上涨”分类的朴素基准也会得到 67.0% accuracy；分类结果不能取代收益误差和下行风险评估。

## 当前结论与下一步

首轮研究说明结果分布有强烈年份差异、重尾和显著下行风险。当前数据不足以支持“打新模型已有效”的结论。主要缺口是招股截止前可核验的特征快照、配发明细和申购成本。

下一步应建立公告时间戳明确的特征表，优先整理招股书里的发行价区间、发行股数、募资用途、基石/国际配售和保荐人；再加入最终配发结果和每个申购档位获配数量，构造真正的获配调整后净收益。届时使用滚动年度样本外评估，并报告 IPO 级别的不确定性。
