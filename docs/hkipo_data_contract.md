# 港股次新股数据契约（第一版）

数据以 `listing_event_id` 为上市事件标识，推荐由 `stock_code` 与 `listing_date` 拼接生成。证券代码可能在退市后重新使用，因此仅用 `stock_code` 不能唯一标识 IPO。转板、介绍上市或特殊证券应先排除或单独标注。

## IPO 主表

每只 IPO 一行：

| 字段 | 必需 | 说明 |
| --- | --- | --- |
| `stock_code` | 是 | 港交所证券代码，保存为字符串并补足五位 |
| `listing_date` | 是 | 正式开始交易日期 |
| `listing_event_id` | 自动生成 | `stock_code + listing_date`，标识一次上市事件 |
| `ipo_price` | 是 | 最终发行价；不得使用上市后调整价格替代 |
| `lot_size` | 否 | 每手股数；建立可交易回测前必须补齐 |
| `offer_shares` | 否 | 全球发售股数 |
| `public_offer_shares` | 否 | 香港公开发售股数；应随最终回拨结果更新并记录发布时间 |
| `free_float_shares` | 否 | 上市时自由流通股数；记录计算口径和来源 |
| `cornerstone_pct` | 否 | 基石配售占比 |
| `greenshoe_shares` | 否 | 超额配股权股数/比例 |
| `stabilization_start_date` | 否 | 招股文件/公告披露的稳定价格期开始日 |
| `stabilization_end_date` | 否 | 规则窗口结束日；另存实际稳定价格操作公告，不推断为连续护盘 |
| `feature_available_at` | 否 | 特征最早公开时间；对静态特征也应保留来源时间戳 |

保荐人、行业、PE/PS、基石名单、超购倍数、中签率及最终分配数据可分表维护。任何分配结果或最终超购倍数都只能用于其公布之后的决策状态。

## 日线表

每只 IPO 事件每个交易日一行：

`listing_event_id,stock_code,date,open,high,low,close,volume,turnover`

OHLC 使用未复权交易价格，以便正确计算相对发行价的溢价和成交价。若另存复权价格，需单独列名并记录公司行动调整口径。`turnover` 为港元成交额；`volume` 为股数。缺失交易日、停牌和无成交日必须按市场记录处理，不能简单以前值伪造成交。

探索阶段可以使用 Yahoo/yfinance 等易得行情，但每批数据都应保留来源、覆盖范围、原始文件和调整口径，并把 OHLC 冲突、缺失与映射问题列入质量报告。导入时遇到重复证券/日期或非正价格应报错；不得用另一来源静默覆盖，也不得自动修复异常。若未来需要更严谨地估计可交易表现，再考虑 HKEX 授权历史数据或说明授权来源、覆盖范围和价格口径的供应商。

当前 Yahoo/yfinance 行情定位为探索性数据，不代表官方行情。可选 CSV 导入入口：`src/hkipo/import_bars_csv.py`。它要求显式字段映射，保留文件 SHA-256 与来源标记，限定未复权价格，并生成 OHLC 质量摘要。

## 时点和回测规则

- 特征按**决策时点**管理。收盘后计算的日线特征只能从下一可交易时点开始成交。
- 每个 IPO 事件整体分配到单一训练、验证或测试分区；按上市日排序做前推评估，不随机拆分单只股票的交易日。
- 成交模型应采用下一时点开盘/可成交报价并考虑整手、流动性、停牌和无法成交情况；日线 OHLC 不足以模拟排队和盘中冲击。
- 交易费用按交易日留存参数，至少包括印花税、HKEX 交易费、SFC 交易征费、AFRC 交易征费、券商佣金和滑点。

`src/hkipo/data.py` 当前负责字段校验、事件窗口筛选和截至各日收盘可观测的基础特征，不产生未来目标或交易信号。
